PACK DE ÍCONES DE TECNOLOGIAS

Os ícones de marcas/tecnologias foram derivados da família Simple Icons 14.9.0
instalada no ambiente, mantendo os desenhos vetoriais e as cores de marca
correspondentes quando disponíveis.

Incluídos:
HTML5, CSS3, JavaScript, TypeScript, Git, GitHub, Figma, React, Python,
Jupyter, Node.js, PostgreSQL, Docker e Scrum Alliance.

Observação:
SQL não possui um único logotipo oficial universal. O arquivo sql.svg é,
portanto, um símbolo neutro de SQL/database criado para representar a
tecnologia sem atribuí-lo a uma empresa específica.

Scrum:
scrum.svg representa Scrum Alliance, uma organização ligada ao Scrum, e não
um logotipo universal do framework Scrum.

Fonte dos desenhos de marca: Simple Icons.
